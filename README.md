# 🚀 My GitHub Projects Overview

For more details about each project, visit the corresponding GitHub repository! 😊 Some repos have multiple domains so they are duplicated in different sections. Many projects are not finished.

I'm always responding to people but I missed too often GitHub notifications, so I realize months later that people opened a ticket. If this case happens it's better to reach me directly on Discord.

By the way: I have a GitHub sponsor page: https://github.com/sponsors/Lecrapouille. If you like my work, please consider sponsoring me!

## 🤖 Robotics Projects

- **[Arduino Emulator](https://github.com/Lecrapouille/ArduinoEmulator)**: Arduino hardware emulator for testing Arduino sketches without physical hardware. Mainly created for testing [Timed Petri Net Editor](https://github.com/Lecrapouille/TimedPetriNetEditor).
- **[Behavior Tree](https://github.com/Lecrapouille/BlackThorn)**: A lightweight behavior trees C++ library with its graphical editor and real-time visualizer (WIP). Created because I did not like some part of the mainstream library used in robotic. 
- **[Prologot](https://github.com/Lecrapouille/Prologot)**: Integrate SWI-Prolog into Godot 4, because sometimes we need a different way to create game logic.
- **[Robotik](https://github.com/Lecrapouille/Robotik)**: A C++ robot kinematics library with its graphical editor, created for learning that solving a problem for the community (WIP, use with care!).
- **[Highway](https://github.com/Lecrapouille/Highway)**: Autonomous driving simulator (WIP, currently private). A public prototype is given [here](https://github.com/Lecrapouille/BacASable/tree/master/LawControl/AutoParking). Created because I did not like Carla simulator.
- **[Control Law](https://github.com/Lecrapouille/BacASable/tree/master/LawControl)**: Proof of concepts on control law.

## 🛠️ C++ Libraries

- **[My Makefile](https://github.com/Lecrapouille/MyMakefile)**: Makefile macros used for compiling all my C++ GitHub projects with all utilities needed: static and shared lib, pkg-config, all compilation flags (asan, stack trace, ...). Created because I disliked CMake, specially it cannot create both static and shared lib.
- **[Zipper](https://github.com/Lecrapouille/zipper)**: C++ zip/unzip wrapper library.
- **[MQTT](https://github.com/Lecrapouille/MQTT)**: Simple C++ MQTT client library (mosquito wrapper).
- **[Dynamic Library](https://github.com/Lecrapouille/DynamicLibrary)**: C++ auto-reload shared libraries.
- **[My Logger](https://github.com/Lecrapouille/MyLogger)**: Used to be a simple C++ logger, now turning to a log tracer project (WIP, use with car !).
- **[OpenGL C++ Wrapper](https://github.com/Lecrapouille/OpenGLCppWrapper)**: C++ OpenGL Core wrapper (canceled project).

## 🚗 Traffic Simulation

- **[CiudadSim](https://github.com/Lecrapouille/CiudadSim)**: Scilab Traffic Assignment Toolboxes (I'm not the author of the original code).

- **[SimTaDyn](https://github.com/Lecrapouille/SimTaDyn)**: proof of concept project for a geographic information system allowing to draw geographic maps and manipulate them like a spreadsheet (Excel).
